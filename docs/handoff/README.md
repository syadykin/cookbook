# Рецепти — пакет для розробки

Мінімалістичний застосунок для зберігання власних рецептів. Mobile first, одна вузька колонка, на екрані — лише рецепт; решта керування прихована й з'являється при наведенні (на телефоні — за дотиком або видима, але приглушена).

**Стек:** React (фронтенд) · Go (бекенд) · OpenAPI (контракт) · SQLite (дані). Структуру репозиторію, інструменти генерації коду з OpenAPI, роутер, міграції тощо — взяти як у попередньому проєкті «Шухляда».

## Що в пакеті

| Шлях | Що це |
|---|---|
| `design/*.dc.html` | Екрани з макета: розмітка, стилі й логіка взаємодії. **Еталон, не код для запуску**: файли написані у форматі дизайн-полотна (`{{змінні}}`, `<sc-for>`, `<sc-if>`, клас `Component extends DCLogic`) і працюють лише в ньому. Перенести в React-компоненти, зберігши вигляд і поведінку. |
| `design/tokens.css` | Дизайн-токени як CSS-змінні + правило «показати при наведенні». |
| `api/openapi.yaml` | Чернетка контракту API. |
| `api/schema.sql` | Чернетка схеми SQLite. |

Інтерактивний макет: https://claude.ai/artifact/Q1XB11GdrXcpz59ywiGUQA (приватний, доступний власнику).

## Екрани й маршрути

| Маршрут | Файл макета | Зміст |
|---|---|---|
| `/login` | `Login.dc.html` | Заголовок «Рецепти», підпис, кнопка «Увійти через Google». |
| `/` | `Library.dc.html` | Список рецептів: пошук, рядок тегів-фільтрів, «+» новий рецепт, аватар → меню (ім'я, email, «Вийти»). |
| `/r/:id` | `Main.dc.html` | Рецепт: перегляд і редагування на одній сторінці. |
| `/r/new` | `Main.dc.html` | Новий рецепт: створюється порожнім і відкривається в режимі редагування. |
| `/r/:id/cook` | `Cook.dc.html` | Режим готування: свайп-слайди. |

Неавтентифікований користувач на будь-якому маршруті → `/login?return_to=…`.

## Поведінка

### Загальне
- Одна колонка `max-width: 640px`, бічні відступи 20 px; на телефоні 390 px — еталонна ширина.
- **Приховане керування.** Елементи з класом `hov` у макеті (у токенах — `.reveal-on-hover`) мають `opacity: 0` і стають видимими при `:hover` батьківської зони (лише `@media (hover: hover)`), при `:focus-within` і завжди на сенсорних екранах, якщо позначені `tch` (`.touch-visible`). Так поводяться: верхня панель перегляду рецепта, −/+ порцій, «+» і аватар у списку, ручки перетягування й видалення в редагуванні, дата внизу рецепта.
- Цілі дотику ≥ 44 px; кнопки-іконки мають `aria-label`; контраст тексту ≥ 4.5:1 (найсвітліший текст — `#6B6B69`).
- Заголовки — Caveat, текст — Inter. Пастельні кольори — лише фони; текст на них завжди `--text`.

### Перегляд рецепта (`Main`, стан `editing = false`)
- Зверху: час, назва (Caveat), опис, теги-«пігулки» (кольори по колу з палітри).
- Фото: велике (4:3, обкладинка = перше) + мініатюри 64 px; дотик по мініатюрі змінює велике фото.
- **Інгредієнти:** дотик по рядку закреслює його (локальний стан, не зберігається). −/+ змінює кількість порцій 1–24; кількості, що починаються з числа, перераховуються: `число × поточні / базові`, округлення до 0,1, десяткова кома, решта рядка — одиниця («500 г» → «625 г»). Нечислові («дрібка», «за смаком») не змінюються. Відмінювання: «на 1 порцію / 2–4 порції / 5+ порцій».
- **Приготування:** нумеровані кроки (номер — пастельне коло, Caveat). Фото кроку 104×78; дотик розгортає фото на всю ширину (220 px висоти), повторний — згортає.
- Кнопка «▶ Готувати» біля заголовка «Приготування» → режим готування.
- **Таймер** (якщо в кроку задано `timerSeconds`) — див. нижче.
- Панель угорі: ← до списку, олівець → редагування, «⋯» (меню дій, наразі порожнє).

### Редагування на тій самій сторінці (`editing = true`)
- Олівець вмикає режим; панель угорі замінюється на «Редагування» + пігулка «Готово» (зберігає `PUT /recipes/{id}` і повертає перегляд).
- Тексти стають полями, візуально такими самими, з пунктирним підкресленням; фокус — світлий фон і суцільна лінія.
- Теги: «×» на кожному, поле «+ тег» — Enter додає (нижній регістр, без дублів).
- Фото рецепта й кроків: «×» на кожному, плитка «+» — додати. Перше фото — обкладинка.
- Інгредієнти: ручка перетягування · назва · кількість (один текстовий рядок) · «×»; кнопка «+ Додати інгредієнт».
- Кроки: номер, ручка перетягування, кошик; текст; фото; поле **«Таймер, хв»** (дробові допустимі, порожнє = без таймера; у API — секунди); «+ Додати крок».
- Поле «Порцій» — базова кількість, для якої записані інгредієнти.
- Унизу — «Видалити рецепт» (червоний текст; потрібне підтвердження).
- Збереження: рекомендовано автозбереження чернетки локально + явне «Готово»; конфлікт версій → 412, показати користувачу.

### Вибір джерела фото
- **Телефон** (не `(hover: hover) and (pointer: fine)`): плитка «+» відкриває нижню панель: «Зробити фото» (`<input type="file" accept="image/*" capture="environment">`), «Вибрати з галереї або файлів» (`accept="image/*" multiple`), «Скасувати». Заголовок панелі: «Фото рецепта» / «Фото до кроку N». Закриття дотиком по затемненню.
- **Комп'ютер:** панель не показується, одразу відкривається вибір файлів (`multiple`).
- Кожен файл → `POST /photos` (показувати прев'ю через `URL.createObjectURL` одразу, індикатор завантаження), отриманий `id` додається в `photoIds` рецепта/кроку.

### Режим готування (`Cook`)
- Повноекранний (`100dvh`): хедер (× закрити · назва · перемикач «екран не гасне»), під ним сегменти прогресу (по одному на слайд, клікабельні), внизу «Назад» / «Далі» (на першому — «До кроків», на останньому — пігулка «Готово»).
- Слайд 0 — інгредієнти з −/+ порцій і закреслюванням. Слайди 1…N — кроки: номер, «Крок i з N», текст 20 px, кнопка таймера (якщо є), велике фото 4:3 (дотик — наступне фото, лічильник «1 / 3»), мініатюри 56 px.
- Свайп: pointer events, слайд іде за пальцем; поріг 50 px; на краях опір (dx/3); `touch-action: pan-y`, щоб вертикальний скрол працював; дотик після свайпу не активує кнопки.
- **Екран не гасне:** Screen Wake Lock API (`navigator.wakeLock.request('screen')`), вмикається при вході, повторно — на `visibilitychange`, знімається при виході. Іконка сонце/місяць перемикає. Потрібен HTTPS.

### Таймер кроку
- Стани кнопки: «▶ 10:00» (готовий) → запущений «⏸ 9:42» (фон — акцент) → пауза «▶ 6:12»; поруч «↺» скидання, коли запущено або на паузі.
- Завершення: кнопка персикова, пульсує, «🔔 Час вийшов»; сигнал — 3 короткі тони 880 Гц (Web Audio) + `navigator.vibrate([300,150,300,150,300])`; повтор кожні 4 с, максимум 8 разів, поки не натиснуть кнопку (скидає таймер). `aria-live="assertive"` оголошує «Час вийшов».
- AudioContext створювати/відновлювати під час натискання «старт» (вимога автозапуску браузерів).
- Відлік за `endAt = Date.now() + left`, а не за кількістю тіків. Кілька таймерів можуть працювати одночасно; бажано, щоб стан таймерів жив вище за сторінку (спільний для перегляду й режиму готування) і переживав перехід між ними.

### Список рецептів (`Library`)
- Заголовок «Рецепти» (Caveat 52 px); праворуч «+» і аватар (ініціали на лавандовому колі) — приховані до наведення на десктопі.
- Пошук (світло-сіре поле з лупою) — за назвою й тегами.
- Рядок тегів-фільтрів: горизонтальний скрол без смуги прокрутки; активний тег — пастельний фон; повторний дотик знімає фільтр. Джерело — `GET /tags`.
- Рядок рецепта: мініатюра обкладинки 52 px, назва (Caveat 27 px), «час · теги» (обрізання з трикрапкою), стрілка при наведенні.
- Меню аватара: ім'я, email, роздільник, «Вийти» (`POST /auth/logout` → `/login`). Закривається кліком поза ним.

### Вхід (`Login`)
- По центру: три пастельні крапки, «Рецепти» (Caveat 72 px), «Ваша особиста книга рецептів», кнопка «Увійти через Google» (біла пігулка з рамкою, 50 px). Унизу — «Конфіденційність».
- У реальній кнопці використати офіційний логотип «G» за правилами бренду Google.

## Бекенд — нотатки
- OAuth 2.0 Authorization Code + PKCE, параметр `state` у короткоживучому cookie; з ID token брати `sub`, `email`, `name`, `picture`. Сесія — випадковий токен у `HttpOnly; Secure; SameSite=Lax` cookie, у БД — його sha256.
- Фото: перевіряти реальний тип за вмістом, знімати EXIF (геолокація!), застосовувати орієнтацію, зберігати оригінал ≤ 2048 px і варіанти 160/640/1280 (WebP або JPEG). Файли — на диску поруч із БД, у SQLite — лише метадані. Ліміт розміру завантаження (напр. 15 МБ).
- `PUT /recipes/{id}` виконувати в одній транзакції; `version` — лічильник або хеш `updated_at`.
- SQLite: `PRAGMA foreign_keys=ON`, `journal_mode=WAL`.

## Відкриті питання
- Спільний доступ до рецептів (поділитися посиланням) — наразі не передбачено.
- Перетягування для зміни порядку: на телефоні — довге натискання на ручку.
- Імпорт рецептів з посилань/тексту.
